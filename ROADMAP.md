# Phased Development Roadmap (`ROADMAP.md`) — StudySync

## Phase 1: Local-First Focus Workspace (Current)
- [x] Foundation: Strict TypeScript, design system tokens, CSS variable architecture.
- [x] Headless Timer Engine: Deadline-based clock arithmetic, background catch-up, focus accounting.
- [x] Preset & Custom Modes: 4 built-in presets, custom sequence editor, rotary jog dial, immutable run snapshots.
- [x] Five-Zone Workspace: Top utility bar, sequence pipeline, hero radial dial, tactile control island, floating dock.
- [x] Local-First Storage: IndexedDB adapter, crash/reload recovery, session history, streak analytics.
- [x] Audio Engine: Synthesized Web Audio chimes, local soundscapes (Rain, White Noise, Drone), local audio file playback.
- [x] Comprehensive Automated Tests & Verification.

## Phase 2: Enhanced Analytics & Soundscapes (Planned)
- Heatmap calendars and weekly/monthly focus distribution charts.
- Export/import session data (JSON, CSV).
- Additional generative soundscapes and ambient presets.

## Phase 3: Collaborative Study Rooms & Sync (Future)
- P2P / WebRTC room presence and shared study sessions.
- Room sync without server-side tracking.
